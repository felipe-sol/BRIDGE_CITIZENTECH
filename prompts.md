# Prompts de IA — Bridge

## Sobre o projeto

**Bridge — zeladoria colaborativa de calçadas e vias** (FIAP · Global Solution 2026.2 · CitizenTech)

O Bridge é uma plataforma para o cidadão **registrar problemas de infraestrutura urbana**
(calçada danificada, buraco, iluminação defeituosa, obstáculo à circulação), que a API
**valida, classifica e prioriza** por regras transparentes e **acompanha** por um
histórico de status.

- **Backend (SOA):** API REST em Python (FastAPI, SQLAlchemy, Alembic, PostgreSQL) — `backend/`
- **App (Mobile):** React Native + Expo com TypeScript — `mobile/`

Projeto acadêmico: não há integração oficial com prefeitura ou órgão público.
