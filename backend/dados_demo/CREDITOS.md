# Créditos das fotos ilustrativas

As fotos de `fotos/` **não são dos locais dos registros**: são imagens livres do
[Wikimedia Commons](https://commons.wikimedia.org/), escolhidas pelo assunto de cada registro
(calçada danificada, buraco, iluminação, obstáculo), só para a demonstração do app.
Foram baixadas na largura de 1.000 px; ao importar, o backend as reencoda sem metadados.
